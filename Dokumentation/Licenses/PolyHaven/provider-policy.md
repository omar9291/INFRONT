# Poly Haven provider policy evidence

Reviewed 2026-09-05: https://polyhaven.com/license

The official asset policy identifies the downloadable models, textures and HDRIs as CC0.
Individual creator names and matching source-file hashes are retained in the adjacent
per-asset JSON records from the official API. A metadata record is not an embedded
package licence. The original direct downloads in this repository had no retained
licence file, so that evidence distinction remains explicit.
