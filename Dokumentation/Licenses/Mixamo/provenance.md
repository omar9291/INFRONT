# Mixamo: local-only source record

Reviewed 2026-09-05: https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html

Adobe's FAQ permits use of Mixamo characters and animations in personal and
commercial projects, including video games. This is a service-terms/FAQ source,
not a CC0 dedication or a package-internal licence.

The project retains basis.fbx, idle.fbx, walk.fbx, run.fbx and death.fbx locally.
The original character and animation catalogue names were not retained. Their
individual source details and the complete redistribution terms remain unresolved.
The current Git policy excludes these files and the generated character prefab.
This audit changes neither that policy nor repository history. A clone may omit
these optional files and use the existing geometric fallback.
