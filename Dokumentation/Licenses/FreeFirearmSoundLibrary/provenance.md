# The Free Firearm Sound Library: retained provenance

Reviewed 2026-09-05: https://opengameart.org/content/the-free-firearm-sound-library

The distribution page identifies CC0 and lists Ben Jaszczak, Brian Nelson, Kevin
Heras and Matthew Nanney as creators/recordists. The existing project inventory
associates the four installed shot files with this library. It describes trimming,
fades, volume normalization and conversion to 44.1 kHz, 16-bit mono.

Update 2026-09-06: the original archive was downloaded and inspected. Its hash and
member list are retained in `archive-inspection.json`; the 194 MB download stays
outside the game repository. There is no standalone licence file in the archive.
Selected embedded BWF metadata describes the recording, not its licence.

Unresolved: a package-internal licence and the exact original edit mapping remain
unavailable. The current file fingerprints identify the edited files;
they do not independently prove which source take produced each edit. Do not label
this entry package-licence-verified without recovering that evidence.
