# The Free Firearm Sound Library: retained provenance

Reviewed 2026-09-05: https://opengameart.org/content/the-free-firearm-sound-library

The distribution page identifies CC0 and lists Ben Jaszczak, Brian Nelson, Kevin
Heras and Matthew Nanney as creators/recordists. The existing project inventory
associates the four installed shot files with this library. It describes trimming,
fades, volume normalization and conversion to 44.1 kHz, 16-bit mono.
