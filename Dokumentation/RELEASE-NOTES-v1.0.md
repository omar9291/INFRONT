# INFRONT v1.0

Erste öffentliche Test-Version. Ein Spieler gegen Bots im Host-Modus.

## Drin

- Zwei Spielmodi: **Ausscheiden** und **Bombe**
- Einstellbare Teamgröße (2–5) und Bot-Stärke (leicht / normal / schwer)
- Neu aufgebautes Hauptmenü mit getrennten Bereichen: Spielen / Einstellungen / Steuerung
- Kauf­menü, Punktetabelle, Kill-Feed, Ladebildschirm
- Bild-Einstellungen (voll / schlicht), Maus-Empfindlichkeit, Lautstärke

## Bekannte Grenzen

- Nur Host-Modus, kein Online-Multiplayer über Internet
- Gegner sind Bots, keine echten Spieler
- Waffen und Figuren teilweise noch mit Platzhalter-Modellen
- Optisch noch nicht auf allen Rechnern geprüft

## Start

**macOS:** ZIP entpacken → Rechtsklick auf `INFRONT.app` → Öffnen (nicht doppelklicken).
**Windows:** ZIP entpacken → `INFRONT.exe` → bei SmartScreen *Weitere Informationen → Trotzdem ausführen*.

Rückmeldungen gern als [Issue](../../issues) oder direkt an Driftlab.
